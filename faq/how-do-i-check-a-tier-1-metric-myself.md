Tier 1 means the value is computable directly from an on-chain source by a query anyone can reproduce. Five metrics are additionally read from two independent sources and reconciled to exact agreement. For several metrics the reproduction path exists today: the Dune queries behind the reconciled metrics are published as validated SQL that anyone with a free account can re-run, and each metric page names its source endpoints and parameters. A step-by-step reproduction walkthrough, taking one metric from raw query to published value, is planned with the documentation section.
