The portal's prose lives in a public content repository; open a pull request there. Continuous integration enforces the style rules mechanically and a maintainer reviews substance, with methodology-relevant pages requiring a domain reviewer. Prose contributions are licensed under CC BY 4.0. The source code repository is scheduled for public release under Intersect's Open Source Office, and code contributions follow its contributing guide once it is open.
