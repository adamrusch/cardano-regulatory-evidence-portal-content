---
id: verbatim-versus-paraphrase
question: What is the difference between verbatim and paraphrase labels on provisions?
audience: [regulator, academic]
category: statutory
status: locked
last_reviewed: "2026-08-08"
---

Verbatim means the quoted words reproduce the cited instrument's published text exactly, verified against the source before entry; those appear in quotation marks. Paraphrase means the provision is described in the mapping's own words, either because the enrolled text is not yet published, as with the Senate merged text, or because the source document was not quoted directly. The label is shown on every provision so a reader always knows which discipline applies. Composing statutory-sounding language and calling it verbatim would falsify the record, so the rule is enforced as strictly as the numbers are.
