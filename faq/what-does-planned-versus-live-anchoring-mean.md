The banner states the current truth: no Merkle root from this portal has been published to any Cardano network for the mainnet record, so today's values are traceable to their sources but not yet verifiable against an on-chain root. The anchoring machinery itself is built and has been proven end to end on the preprod test network, including independent verification from public data alone. Mainnet anchoring is gated behind a published readiness checklist and begins when the portal moves to production infrastructure; the banner will state the start date when it happens.
