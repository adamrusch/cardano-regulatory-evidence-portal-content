Dune is an analytics platform that indexes blockchain data and lets anyone run SQL queries against it in a browser. The portal uses Dune as its public witness: the exact SQL behind each Dune-sourced reading is published, so a reader with a free account can re-run the query and compare the result. Dune is independent of the Cardano ecosystem's own infrastructure, which is what makes agreement between Koios and Dune informative.
