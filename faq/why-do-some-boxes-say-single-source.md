A metric labeled single source has been read from exactly one source on this run. It has not been agreed against an independent second source, so the site cannot claim cross-source reconciliation for it. Rather than paper over that fact with a badge that implies confirmation the pipeline did not perform, the metric carries the single-source label on every surface where its value appears.
